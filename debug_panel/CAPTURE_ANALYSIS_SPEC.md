# xray-rs 抓包分析与统计工具需求清单

> 聚焦**抓包 + 统计 + 流量特征分析**（仅 `debug_assertions` 生效，Release 零开销），用于观察 `xray-rs` 的连接复用、延迟与资源消耗，并对比**直连正常流量**与**代理流量**的特征差异，同时提供极简接口给 AI 直接分析。

---

## 1. 抓包采集层（抓什么）

| 维度 | 核心字段 | 用途 |
|---|---|---|
| **基础元数据** | 序号 `seq`、毫秒时间戳 `ts_ms`、同流包间隔 `iat_ms`、连接 ID `conn_id` | 还原时序、分析包间隔节奏（burst / pacing） |
| **五元组与路由** | 源 `src`、目标 `host:port`、方向 `C->S` / `S->C`、出站标签 `outbound`、是否直连 `bypassed` | 区分不同网站、区分直连与代理流量 |
| **长度信息** | 原始块长度 `length`、累计上下行字节、流内第 N 个包 | 分析首包特征、MTU 分片、包长分布 |
| **L7 协议解析** | `TLS`（ClientHello / ServerHello / Cert / AppData + Record 长度）、`HTTP`（方法/状态码/Host/Connection）、`TCP` 原始负载 | 无需 Npcap 即可直接看清应用层行为 |
| **原始负载截取** | 前 `256B~1024B` 原始字节（Hex + ASCII） | 排查协议握手细节与导出 `.pcap` |

---

## 2. 统计维度（算什么）

### 2.1 按网站（Host）连接与复用统计
- **连接计数**：新建连接数 `established`、复用连接数 `reused`、复用率 `reuse_rate_pct`、当前活跃 `active`、失败数 `failed`。
- **延迟分布**：建连耗时 `avg / min / p50 / p95 / max (ms)`、首包耗时 `TTFB (ms)`、连接平均存活时长。
- **流量汇总**：上行/下行总字节、上行/下行总包数、上下行比例（`up/down ratio`）。

### 2.2 包长与时序统计（流量特征核心）
- **包长分布桶（Histogram）**：`<100B`、`100-512B`、`512-1200B`、`1200-1460B`、`>1460B`（以及均值、标准差）。
- **前 N 包序列指纹（First-N Packet Sizes）**：记录每条连接前 5~10 个包的带符号长度序列（如 `[+517, -1420, -1420, +64, ...]`），最直观反映正常 TLS 握手 vs 代理封装的差异。
- **包间隔统计（IAT, Inter-Arrival Time）**：同连接相邻包的时间间隔分布，识别卡顿、粘包或定时心跳。
- **TLS 握手特征**：Record 版本、Handshake 版本、SNI、ALPN、Cipher Suite 数量、Extension 数量、ClientHello 总长度（可选扩展 JA3/JA4 哈希）。

### 2.3 进程资源统计
- **CPU %**、**内存 RSS / Private / Peak (MB)**、活跃连接数与资源占用联动采样（保留最近 60 秒趋势）。

## 3. 核心分析能力（重点看什么）

### 3.1 直连正常流量 vs 代理流量 A/B 对比
- 通过「直连内核不代理」模式与正常代理模式分别访问同一网站，自动对比：
  1. **建连 & 首包延迟差**（直连 ms vs 代理 ms）
  2. **连接数与复用率差**（同一网页分别建了多少连接、复用了多少）
  3. **首包 / 前 5 包长度序列差**（是否存在明显固定长度、异常小包或额外 RTT）
  4. **包长分布与上下行比例差**

### 3.2 自动异常标注（一眼发现问题）
- **低复用告警**：同一网站新建连接过多、复用率接近 0%。
- **高延迟 / 抖动告警**：建连 `p95` 或 `max` 远高于均值。
- **频繁失败 / 短命连接**：失败率高或大量连接不足 1 秒断开。
- **明显特征偏移**：代理流量的首包长度/包长桶分布与直连基线差异过大。

## 4. 导出与极简 AI 接口

### 4.1 人工查看与外部工具
- **单页 Web 面板**（`http://127.0.0.1:19876/`）：按域名/方向/协议筛选、看统计表与 Hex 负载。
- **标准 `.pcap` 导出**（`/ai/capture.pcap`）：需要深度 TCP/TLS 解码时直接拖进 Wireshark。

### 4.2 给 AI 用的极简接口（低 Token、单次调用）
- `GET /ai/summary?format=text`：全局资源 + 连接/复用汇总 + 抓包统计一页摘要。
- `GET /ai/sites?host=xxx`：单网站详细连接、复用、延迟与流量特征。
- `GET /ai/packets?host=xxx&limit=50&format=text`：逐包摘要（含方向、包长、L7 Info）。
- `GET /ai/compare?host=xxx`（建议新增）：直接返回某网站**直连 vs 代理**的指标对比 JSON/文本。
- `GET /ai/capture?on=1` / `?off=1` & `GET /ai/bypass?on=1` / `?off=1`：一键控制抓包与直连对比。
