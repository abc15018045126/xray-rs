极简 AI 接口 (给 AI Agent 单次调用)
• GET /ai/summary?format=text — 全局资源 + 连接复用 + 抓包总览（最省 Token）
• GET /ai/traces?host=xxx&format=text — 单连接全链路每步耗时（嗅探 / 路由 / TCP / TLS / WS / 首包 / TTFB）
• GET /ai/pageloads?host=xxx&format=text — 网站打开总耗时（按主站归拢）
• GET /ai/cpu?format=text — CPU 归因（用户态/内核态拆解 + 线程级排行 + 出站负载）
• GET /ai/compare?host=xxx&format=text — 直连 vs 代理同站自动 A/B 对比（P50/P95/TTFB/前 N 包指纹）
• GET /ai/flows?host=xxx&format=text — 每条连接的 conn_id、IAT ms 与前 N 包长度序列指纹
• GET /ai/packets?host=xxx&format=text — Wireshark 逐包摘要（含 conn_id 与 iat_ms）
• GET /ai/capture.pcap — 下载标准 Wireshark `.pcap` 文件
• GET /ai/bypass?on=1 / ?off=1 · GET /ai/capture?on=1 / ?off=1 · GET /ai/probe?target=www.cloudflare.com
